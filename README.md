> **Tecnologias:** JavaScript, Ecossistema Front-End, UI/UX de Alta Performance.

#### 🏋️‍♂️ [CT R.A.S — Centro de Treinamento](https://ct-r-a-s.vercel.app/)
Landing page premium desenvolvida para um centro de treinamento de alta performance. Combina uma estética forte e moderna com otimização no front-end, garantindo carregamento rápido, recursos interativos e total responsividade.

> **Tecnologias:** Java, Spring Boot, React, JavaScript.

#### 🚗 [Garagem 7 — Estética Automotiva Premium](https://garagem-7.vercel.app/)
Landing page premium desenvolvida para o segmento automotivo de alto padrão. Conta com elementos dinâmicos, carrosséis de serviços, catálogo interativo e agendamento via modais.
